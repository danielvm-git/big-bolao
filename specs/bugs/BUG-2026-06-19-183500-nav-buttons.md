# BUG-2026-06-19-183500: Bottom navigation buttons unresponsive

## Problem

The bottom navigation bar (Início / Jogos / Ranking / Meus) renders visually but the buttons do not respond to clicks. Clicking any nav button produces no navigation — the view stays on the current page.

**Expected**: Clicking "Jogos" navigates to the games list; clicking "Ranking" navigates to the ranking table; clicking "Meus" navigates to my predictions page.

**Actual**: No response — the URL does not change and the view does not switch.

**How to reproduce**:
1. Open the Big Bolão site
2. Log in as any participant
3. From the Home screen, click any bottom nav button (Jogos, Ranking, or Meus)

## Root Cause Analysis

**Two compounding issues:**

1. **`<router-view v-slot="{ Component }">` with `<transition>` fails to resolve route components.** Vue Router 4's scoped-slot syntax with `v-slot` and `<transition mode="out-in">` wrapping `<component :is="Component" />` was not rendering the matched route component. The DOM showed `<!---->` (Vue's empty placeholder) instead of the expected view. Removing the `v-slot`+`transition` wrapper and using plain `<router-view />` fixed route component resolution.

2. **`v-if`/`v-else` wrapping broke router-view mount.** The original `App.vue` placed `router-view` inside a `v-else` branch that was conditionally mounted/destroyed on login state change. Combined with issue #1, this meant the router outlet never properly registered.

**Fix**: 
- Use plain `<router-view />` (no v-slot, no transition wrapper)
- Keep `router-view` always in the DOM as a sibling of `LoginView` (which overlays it via `position: absolute` when not logged in)

**Risk level**: Low — fix is confined to App.vue layout. No API changes, no data changes.

## Resolution

**Fixed:** 2026-06-19
**Root cause confirmed:** Two issues in App.vue — (1) `<router-view v-slot="{ Component }">` with `<transition>` wrapper did not resolve lazy-loaded route components in Vue Router 4; (2) `v-if`/`v-else` conditional mounting broke router outlet registration.
**Fix applied:** Replaced `<router-view v-slot="..."><transition>...</router-view>` with plain `<router-view />`; LoginView now overlays via `position: absolute` instead of conditionally replacing `router-view`.
